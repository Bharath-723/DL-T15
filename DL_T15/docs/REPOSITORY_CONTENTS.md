# Repository contents

- `notebooks/`: submitted Colab notebook with outputs retained.
- `src/`: reusable data, model, evaluation and plotting helpers.
- `figures/`: PNG exports of the twelve plots embedded in the submitted notebook.
- `results/`: CSV tables transcribed from the notebook's saved outputs.
- `docs/`: experiment notes and a methodological audit.
- `data/`: dataset source and download notes; source data is not duplicated.
- `report/`: report draft in DOCX and PDF format.

The Python modules are helper extractions, not a replacement for running the notebook. The notebook remains the canonical record for the current captured experiment. Refer to `docs/NOTEBOOK_AUDIT.md` for issues that require correction before final claims.
